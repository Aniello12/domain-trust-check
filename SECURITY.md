# Security policy

## Supported version

Security fixes are applied to the current `main` branch during the beta.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose data, enable SSRF, bypass input validation, or materially alter a score. Until a private reporting contact is configured, contact the repository owner directly through GitHub with a concise reproduction and impact description.

Do not include credentials, customer data, or email content in a report.
